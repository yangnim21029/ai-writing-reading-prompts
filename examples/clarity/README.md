# 清晰度修訂：論文 Prompt 與短 Prompt

同一段圖書館試辦報告，分別交給一般修訂指令與 From Planning to Revision 附錄 C.3.2 的清晰度模板。這組比較的是回覆如何定位問題、提出修改，以及修改是否維持原文的語氣強度。

[回到示範目錄](../README.md) · [原始研究 Prompt](https://arxiv.org/html/2604.11009v2#A3.SS3.SSS2) · [本庫原始模板](../../writing-revision/2604.11009-planning-to-revision/prompts/06-writing-clarity.en.txt)

## 共用素材

232 個中文字，不計標點與空白。素材為本次示範撰寫，兩組使用相同內容。

> 本館上學期試辦延長夜間開放，原先希望讓白天無法到館的學生也能使用空間，但後來的調查發現，表示滿意的人主要是原本就常來的學生，因此這項措施對新使用者的幫助可能沒有預期多。問卷共有八十人回覆，其中六十人曾在晚上使用圖書館，不過這不表示晚上到館的人有四分之三都滿意，因為兩個問題的回答並不一樣。館員認為繼續辦理有其必要，但如果沒有增加人力，延長的部分會影響原來工作，所以建議先保留每週兩天，再觀察一學期。這個安排並不是否定學生的需求，而是在目前條件下，讓服務能夠持續，同時也需要把沒有來的人為何沒來弄清楚。

## 實際使用的提示

短 prompt 由模型在未接觸論文模板的條件下另外產生，要求不超過 35 個英文單字。原始生成請求與回覆保存在 [baseline-generation](../baseline-generation/)。

```text
Identify vague phrasing, logical gaps, and awkward structure in the attached text. Provide specific revision suggestions to enhance readability, flow, and overall precision of the message.
```

[完整短 prompt 與素材](short-prompt.txt) · [填入素材的論文 prompt](paper-prompt.txt) · [兩組共用指示](common-instructions.txt)

原英文模板只將 {draft} 換成這份中文素材；兩組共同加入繁體中文與 200–300 字的輸出要求。沒有將模型產出的建議套回原文，以免另一次改寫混入比較。

兩組都要求以繁體中文回答，目標為 200–300 個中文字。實際長度依模型輸出計算，沒有事後刪改文字。API 實際回傳模型為 Gemini 3.6 Flash；模型路由與設定詳見[實作紀錄](../README.md#模型與執行紀錄)。
