# 角色第一人稱敘事：論文 Prompt 與短 Prompt

以舊書店交接的情節為素材，將一般第一人稱改寫指令與 Narrative Keyframing 附錄 A.5 比較。兩組都以林安為敘述者，採相同 JSON 輸出結構。這裡只測試 A.5 的視角生成模板，沒有執行整套 Narrative Keyframing 流程。

## 共用素材

225 個中文字，不計標點與空白。素材為本次示範撰寫，兩組使用相同內容。

> 林安回到父親留下的舊書店，準備在傍晚把鑰匙交給新店主。她已經簽好轉讓文件，也答應姐姐不再拖延。整理櫃檯時，她找到一本被雨水泡皺的帳簿，最後一頁記著幾位欠款讀者的名字，旁邊卻都寫了「已還」。她認得其中一位是每天坐在門口看書、很少買書的老人。姐姐打電話來問她是否出發，她只說還有一個抽屜沒清完。五點的鐘聲響起，新店主在玻璃門外等候。林安沒有撕掉文件，也沒有決定留下書店。她把帳簿收進自己的帆布袋，關掉櫃檯的燈，走過父親從前坐著的位置，才把鑰匙交出去。雨仍在下，門口那張留給讀者的椅子已經被搬到騎樓深處。

## 實際使用的提示

短 prompt 由模型在未接觸論文模板的條件下另外產生，要求不超過 35 個英文單字。原始生成請求與回覆保存在 [baseline-generation](../baseline-generation/)。

```text
Rewrite the provided plot outline as an engaging first-person narrative from the perspective of Lin An (林安), capturing their internal thoughts, emotional tone, and immediate reactions to the events.
```

[完整短 prompt 與素材](short-prompt.txt) · [填入素材的論文 prompt](paper-prompt.txt) · [兩組共用指示](common-instructions.txt)

以同一段素材填入 Full story 與 Targeting plot，因此論文條件在 prompt 內出現同一素材兩次；沒有增加新的情節資訊。保留無 character keyframe 的分支，移除不適用的分支，兩組共同指定 JSON 欄位 narration。

兩組都要求以繁體中文回答，目標為 200–300 個中文字。實際長度依模型輸出計算，沒有事後刪改文字。API 實際回傳模型為 Gemini 3.6 Flash；模型路由與設定詳見[實作紀錄](../README.md#模型與執行紀錄)。
